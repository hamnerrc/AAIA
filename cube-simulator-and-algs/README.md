# Cube Simulator and Algorithms

Minimal standalone folder containing the cube solver/simulator and last-layer algorithms database.

## Contents

- **solver.html** — Cube solver & move simulator
- **algs.html** — Last-layer algorithms reference
- **crossSolver/** — WASM cube solver engine
- **js/** — Essential JavaScript modules for UI and algorithm display
- **data/** — Algorithm datasets and cube state data
- **styles.css** — Shared styling

## Usage

Open either HTML file in a browser:
- `solver.html` for the interactive cube simulator
- `algs.html` for the algorithms reference

The solver requires the WASM module from `crossSolver/` to be available.

## Ready to Move

This folder can be moved to another directory as-is. All relative paths are self-contained within this structure.
